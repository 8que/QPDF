# QPDF · 雀雀 PDF 使用说明（V1.1 绿色版）

面向大型工程图纸的 PDF 标注工具。双击 `QPDF.exe` 就能用，不需要安装 Python、不需要联网、不需要管理员权限，放 U 盘里换台电脑照样跑。

---

## 一、运行环境

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11（64 位） |
| 内存 | 4 GB 起，8 GB 更稳 |
| 磁盘 | 装程序约 110 MB；处理图纸时另需原件同等的磁盘空间用于导出 |
| 网络 | 完全不需要，全程离线 |

## 二、怎么启动

1. 把整个 `QPDF` 文件夹拷到本地磁盘（**不要只拷 QPDF.exe**，它旁边还有 `_internal`）。
2. 双击 `QPDF.exe`。
3. 首次启动约 0.7–3 秒（老机器慢些），之后都在 1 秒内。

也可以把 PDF 直接拖到窗口里，或者把 PDF 拖到 `QPDF.exe` 图标上。

> 想确认这台机器能不能跑，可以开个命令行执行：
> `QPDF.exe --selftest 你的图纸.pdf`
> 会在程序目录写一份 `selftest.txt`，显示页数、页面尺寸和渲染结果。

## 三、第一次标注

1. **打开图纸**：`文件 → 打开 PDF`（Ctrl+O）。开第二个图纸会多一个标签页，见下面「多标签页」一节。
2. **标数字**：按 **F2**，在图上点一下出一个 1，再点出 2、3、4……自动递增，跨页继续。
   - 想从头再来：按 **Ctrl+Shift+R**，回到 1 重新编号（已有的数字不会动）。
   - 想从别的数开始：`工具 → 数字起始值与步长`，**或者在数字模式下对着图上的空白处点右键**
     （打号打到一半发现起始值/步长不对，就地改，不用跑回菜单）。
3. **标文字**：按 **F5**，点空白处出输入框，打完按 **Enter**（**Shift+Enter** 换行）。
4. **退出当前模式**：按 **Esc**。

标注只在 QPDF 里看得见，**原始 PDF 一个字节都不会被改**。

## 四、标注存哪儿

打开 `图纸.pdf` 时，QPDF 会在同一个文件夹里建 `图纸.qpdf`（标注、编号、工作台位置、操作日志都存在里面，SQLite 格式）。

```
工程图纸/
├── 原始图纸.pdf        ← 你的原件，QPDF 从不修改
├── 原始图纸.qpdf       ← 你的标注都在这里
├── 输出/               ← 导出的 PDF 放这儿（Ctrl+E）
└── 备份/               ← 项目备份，自动留最近 5 份
```

- **自动保存**：停手约 1.5 秒就写一份**存档备份**（`.qpdf.keep` 旁边的那份库），防止断电丢活；但它**不算真正的保存**，状态栏右下角还是显示「● 未保存」。
- **手动保存**：**Ctrl+S**。存完才显示「✓ 已保存 14:32」，标题栏的 `*` 也会消失。
- **关程序时**：如果还有没真正保存的改动，会问「保存 / 不保存 / 取消」。
  - **保存**：存进项目文件，下次打开就是现在的样子。
  - **不保存**：回滚到**上一次手动保存**时的样子（自动存档期间做的改动会丢掉）。
  - **取消**：什么都不做，继续留在程序里。
- **崩溃也不怕**：重新打开同一个 PDF，会恢复到最后一次成功保存的状态。
- **真崩溃了**：程序目录下的 `日志\crash-日期.log` 会记下原因（只留最近 10 个）。
  按表格标注里生成出错时也会自动记这个日志，弹窗里会写出路径——把它发我就行。
- **源文件被动过**：如果 PDF 被移动过位置，QPDF 会重新认一次并提示；如果 PDF 内容被改过（指纹变了）或页数对不上，打开时会列出记录/当前指纹、页数和大小，让你选「继续加载 / 取消加载 / 查看项目位置」。继续加载前会先把旧 `.qpdf` 自动备份到 `备份/`；取消不会改动原文件。
- **从别的电脑拷来的项目**：用 `文件 → 打开项目` 选 `.qpdf`。如果项目里记录的原始 PDF 在本机不存在，会提示你选本机同一套 PDF；选好后项目直接挂到这份 PDF 上，不会因为文件名/目录不同而找不到。指纹对得上就直接载入；对不上仍按上面的「继续加载 / 取消 / 查看位置」处理，继续前先备份原 `.qpdf`。

## 六、修改标注

- **改文字**：双击它。
- **挪位置**：直接拖。
- **改样式**：选中后到右侧「属性」面板调字体、字号、颜色、粗体斜体、对齐、不透明度。
- **删除**：选中按 Delete，或者右键 →「删除标注」。
- **批量**：F6 框选后 Delete，一次撤销能整体恢复。
- **锁定**：Ctrl+L，锁定后拖不动、删不掉，防止手滑。

## 七、工作台（把相关的几页摆在一起看）

一套图纸几百上千页，但某一处管线可能横跨第 4、7、10、15 页。工作台就是把这些页挑出来摆在自由画布上，边看边标，**不影响 PDF 原来的页序**。

- 按 **F7** 打开工作台；**F8** 把当前页丢进去。
- 也可以在左侧缩略图上右键 →「把第 N 页加入工作台」，或者点「添加页面…」输入 `4,7,9-15` 批量加。
- 卡片可以随意拖；「自动排列」按图幅真实比例摆成网格（A1 就是比 A3 大一圈）。
- 摆密了互相压住，就在卡片上右键 →「叠放次序」：置于顶层 / 上移一层 / 下移一层 / 置于底层。
- 放大看细节时卡片会按当前倍数重新渲染，不是把小图拉大糊掉；放大状态照样能标注。
- 卡片上**可以直接标数字、写字、删除**，编号和单页视图是同一套序列，所以第 4 页标 1、第 12 页标 2 会自动连号。
- 能建多个工作台（比如「1 号楼」「水泵房」各一块），卡片位置、叠放次序都跟着 `.qpdf` 一起存。

## 八、导出给别人看

`Ctrl+E`（或 `文件 → 导出 PDF`），默认存到 `输出/图纸_已标注.pdf`，两种形式：

| 形式 | 特点 | 什么时候用 |
| --- | --- | --- |
| **标准注释**（默认） | 写成 PDF 的 FreeText 注释，Adobe / Foxit / WPS / Bluebeam 都能显示，也能继续编辑 | 图纸还要给别人改 |
| **扁平化** | 把标注画进页面内容，任何阅读器都能正常显示，但不能再单独编辑 | 只给别人看、要打印 |

导出是安全的：先写临时文件 → 重新打开核对页数和注释数 → 通过才改名到正式位置。**任何一步失败都不会碰原始 PDF**。

大文件走增量追加（写完一个 1.3 GB 的图纸通常比全量重写快 5 倍左右），遇到加密/签名等不支持增量的文件会自动退回全量重写。

## 九、备份与还原

- **手动备份**：`文件 → 备份项目`，在 `备份/` 里生成 `图纸_20261104_143000.qpdf`，
  自动保留最近 5 份。项目文件很小（通常几十 KB），备份很便宜。
- **自动备份**：程序每 10 分钟会看一眼——只有「这个项目还有改动没手动保存、
  而且上次备份之后又存过盘」才会写一份；你停在那儿不动，它一份都不会多写。
- **找回来**：`文件 → 备份与还原…` 会列出这个项目的所有备份（时间 / 大小 / 文件名），
  选一份点「还原选中的备份」。还原**只换项目文件，原始 PDF 一个字节都不动**，
  而且覆盖前会先自动存一份「还原前」的状态，点错了还能再回来。
- **上次没正常关掉**：如果程序崩溃过或被任务管理器结束，下次打开这份图纸时状态栏会显示
  `● 上次异常退出`，菜单里变成「备份与还原（建议查看）…」。标注一般还在最后一次自动保存里，
  备份里可能有更完整的版本。

## 十、常见问题

**打开 PDF 时提示「对不上」？**
说明这份 PDF 被改过（或者不是原来那份）。QPDF 不会悄悄载入旧标注，而是列出记录/当前指纹、页数和大小，让你自己决定：
- **继续加载**：先自动备份旧 `.qpdf` 到 `备份/`，再打开它；如果标注位置明显不对，用备份恢复原项目。弹窗里可以勾「记住这份 PDF（以后不再提示）」：页数一致时默认勾上，载入成功后会记住这份 PDF 的新指纹，下次不再提示；页数不同时不能勾。
- **取消加载**（默认）：不载入、不改动旧项目。之后如果继续标注，会另建一个项目文件，不会覆盖旧文件。
- **查看项目位置**：打开旧 `.qpdf` 所在文件夹，可以先把它复制走再决定。

**杀毒软件报「未知程序」？**
绿色版没有数字签名，属于正常现象，添加信任即可。程序不联网、不写注册表（配置存在程序目录的 `config/settings.ini`）。

**能把整个文件夹从 U 盘直接运行吗？**
可以。但请注意 `.qpdf` 是写在**PDF 所在目录**里的，U 盘拔走前记得把 `.qpdf` 一起带走。

**标注很多会卡吗？**
不会。标注只存在 SQLite 里，页面是瓦片级按需渲染，2700 页的图纸内存稳定在 250 MB 左右（开发机实测）。

**中文标注在别的软件里显示不对？**
导出时会把 CJK 字体挂到注释自己的 `/DR` 资源上，编辑时不会退回乱码。如果某些阅读器仍显示异常，用「扁平化」导出即可保证任何地方一致。

---

出问题先看程序目录下有没有 `selftest.txt`；还不行就把 `--selftest` 的输出和操作步骤一起反馈，比"打不开"有用得多。

## 自检（打不开/识别不了时先跑这个）

在解压目录里开命令行：

```
QPDF.exe --selftest 某份图纸.pdf    → 结果写 selftest.txt
QPDF.exe --ocrcheck                → 结果写 ocrcheck.txt
```

`--ocrcheck` 会自己画一张管线号的图去识别，能认出来就说明 OCR 链路是好的；
认不出会告诉你系统缺什么语言包。


## 给图纸做书签（管线号识别）

1. **先框识别区域**：`工具 → 设置识别区域…`，在页面上拖一个框，**只框住管线号那一行字**。
   框得太大会把一堆线条框进去，OCR 反而认不出来。
2. **批量识别**：`工具 → 批量识别管线号…`（`Ctrl+Shift+O`），选页码范围，点「开始识别」。
   识别在后台线程跑，扫的时候可以照常翻页看图纸；2712 页大约 3~10 分钟。
3. **校对**：表格里「识别结果」这一列双击就能改，改完点「保存到项目」。
4. **生成书签**：点「生成书签」，之后 `Ctrl+E` 导出 PDF，书签会一起写进去。

连续几页是同一个管线号时只会留一条书签。识别区域按**页面比例**保存，A1/A3 混排也对得上。

## 材料表识别（汇总 Excel）

1. **先框材料表区域**：`工具 → 设置材料表区域…`，在图纸右上角把材料表的
   「材料描述 + 规格」两列框住（画布上出现橙色虚线框）；序号列和数量列不用框，
   表头框不框都可以。每页按同样比例取这块地方。
2. **开始识别**：`工具 → 材料表识别…`（`Ctrl+Shift+D`），页码默认从第 1 页到最后一页，
   空页会自动跳过。点「开始识别」。
3. **看结果**：表格列是「管线号 / 页码 / 序号 / 材质 / 材料 / 标准 / Φ规格 / DN」；
   管线号取该页书签，页码取 PDF 页码。数量不识别、不导出。材质列按国标牌号输出：
   `GB/T14976 S30408` 就写 S30408，`GB/T8163 20` 就写 20，不会把 S30408 截成 304。
4. **导出**：点「导出 Excel…」，默认存到 PDF 同目录的 `材料表汇总.xlsx`。

识别在后台线程跑，结果会顺手存进项目（`material_rows`），关掉再开还在。
如果一条都没识别到，先检查框选区域是不是同时包含「材料描述」和「规格」两列；
**OCR 读不出的规格/DN 会留空，不猜数**。2712 页全跑比较久，
建议先跑前几页确认区域框对了，再放开范围。

## 插入页码

1. **框位置**：`工具 → 设置页码位置…`，在页面上框一块放页码的地方。所有页共用这同一个
   比例位置，翻到哪一页都画在相同位置（画布上会有页码预览）。
2. **设置格式**：`工具 → 插入/设置页码…`（`Ctrl+Shift+N`）。格式里可以写前后文字，
   页码占位符用 `{page}`（或 `{n}`、`{页码}`），总页数用 `{total}`（或 `{总页数}`），
   例如 `第 {page} 页 / 共 {total} 页`、`附图 {page:04d}`。
3. **调样式**：右侧属性面板点「页码」进入页码模式，改字体、字号、颜色、粗体斜体，
   只改页码，不会动到选中的标注。
4. **导出/打印**：`Ctrl+E` 导出时，页码会写进 PDF 页面内容里，打印或发给别人都看得到。
   属性面板选的字体（如宋体、黑体、微软雅黑）会被嵌入导出文件，**不需要勾扁平化**；
   文字复制出来仍是“第 1 页”，不会变成乱码或夹不可见空格。
   `工具 → 清除页码` 可以去掉。

页码不写进 `.qpdf` 的标注库，也不是 `kind='number'` 的焊口数字，所以 qreport 的焊口总量
不会把页码算进去。

### 管理多个工作台

- 工具条上的下拉框显示 `名字（N 页）`，切过去就换一块；
- **复制**：整块复制（页、摆位、备注都带走），适合"同一套图换个区域再看一遍"；
- **备注**：写一句说明，跟着项目一起存，重开还在；
- 工具条下面一直显示备注和 `建于 / 改于` 时间；
- 下拉框右键可以上移、下移、复制、写备注、改名、删除。

## 工作台上删页与清空

- 拖到右下角垃圾桶（拖动时才出现）；
- 选中后按 Delete；
- 右键卡片 →「从工作台移除第 N 页」；
- 工具条「清空」把整块清空（点两下才生效）。

移出工作台不影响 PDF，也不会删标注。

## 识别结果的校对

表格里「采用」没打钩的行不会进书签；「疑似」列标红的是这个标签里不像管线号的字符。
在「疑似」上右键可以忽略这一条、忽略这一类、或忽略某个字符，规则会跟着项目文件走。

**用数据表校对…**（识别对话框底部那个按钮）：选一张 CSV/Excel，软件会拿识别出来的编号
去表里查。查到了就把写法改成表里的（备注写「按表校正：原文 → 新写法」），
查不到就只在备注里列几个候选——**不会替你随便挑一条**。这一列还是你自己说了算，
校对完记得点「保存到项目」。

## 管线号目录

1. 先框识别区域（工具 → 设置识别区域…）；
2. 工具 →「批量识别管线号…」，选页码范围让它跑；
3. 左侧切到「管线号」页签（`Ctrl+Shift+I`），按前缀分组的目录就在那儿。

点目录里的页码就直接跳过去；同一个管线号挂多页会合成一条。顶上「待校对」一组
专门放没识别出东西或看着可疑的页。目录存进 `.qpdf`，导出 PDF 时才转成书签。

## 提取页面

`文件 → 提取页面…` 挑几页另存成新 PDF，标注和书签会一起带过去，原始 PDF 不动。

- **页码一起带过去**：项目里设了页码时，对话框会多一个「页码一起带过去（保留原图页码）」
  勾选项（默认勾上）。提取 301、305 页，输出的页码仍是第 301、305 页，不会重排成 1、2。
- **按目录挑**：图纸自带目录时，对话框里会多一块「按目录挑」。搜或者翻到某一章，
  勾上它，点「把勾选的章节加进页码」，整章的页号就填好了，不用自己数。
- **带一份只含这几页的项目**：勾「同时存一份『只含这几页标注』的项目文件」，
  提取出来的 PDF 旁边会多一个同名 `.qpdf`，里面只有这几页的标注、识别结果和匹配追溯。
  发给别人时把 PDF 和这个 `.qpdf` 一起给，他那边打开就能看到标注。
  （这份子集**页码保持原样**，不是重新从 1 编，所以仍配原来那份图纸。）

## 按编号导出（把一个/几个管线号相关的页提出来）

目录树里认完编号之后，在编号上点右键 → **按编号导出这几页…**（或者
`文件 → 按编号批量导出…`）。选一个或几个编号，程序把它们出现的**所有页**提成一个新 PDF：

- 同一个编号出现在 3 页上，就一起提 3 页；多个编号时**去重、按原页序**排；
- 这几页上的**标注跟着走**，书签会按新页码重排；
- 原始 PDF 不动，输出默认落在 `输出/` 下，文件名带编号（编号里的非法字符会换成 `_`）。

适合"把某个管线的所有图挑出来发给施工队"这种场景——不用一页页翻着挑。

## 目录（PDF 自带的书架）

左侧第三个页签「目录」（`Ctrl+Shift+T`），读的是 PDF 里自带的目录：

- 点一条就跳过去；
- 顶上搜索框按标题筛，命中的会把上级一起展开；
- 识别出来的书签（管线号那套）也会以「OCR · …」的标题并进来，排在对应页上；
- 图纸本身没有目录时，这里会写一句「这份 PDF 没有自带目录」，不会是个空白框。

## 放大窗（可以开多个的小窗口）

画一张详图的时候，常常要同时盯着标题栏、说明或某几行字。

1. **视图 → 设置放大区域…**，在页面上框一块（记的是「页面上的位置」，不是屏幕坐标）；
2. 就开出一个独立小窗，显示那块地方的图，标题写着「第 N 页 · 内容 1.0×」；
3. 翻页时自动换成新一页同一块地方；`Ctrl+Shift+L` 开关全部放大窗；
4. 还要再看另一块？**视图 → 新建放大窗**，或右键现有窗口「新建一个放大窗」——
   新窗口会复制当前区域再错开位置，右键「设置本窗放大区域…」换成另一块即可，多个窗口互不影响。

窗口能做的事：

- **拖着走**：按住标题条拖动；拖到属性栏、左侧栏、画布的边上会自动贴过去，
  拖进属性栏里就贴满那一栏的宽度（跟 PS 的面板吸附一个意思）；
- **改大小**：拉四边或右下角的小斜纹；滚轮也能放大缩小窗口；双击标题条在「大 / 小」之间切；
  右键有「半屏」「整屏」「默认大小」，最小能缩到 40×34 那么一点；标题栏右上角关闭叉
  左边还有一个「−」按钮，点一下**收起到屏幕右下角的小浮条**（不是把窗口缩小）；点浮条
  恢复原来的位置、大小和内容倍率，多个最小化窗口会从下往上排，浮条右键可恢复或关闭这个窗；
- **Ctrl+滚轮 = 缩放内容**：窗口大小不动，框里的图放大/缩小（1×–16×），
  以鼠标指的位置为中心，和主画布缩放 PDF 一个感觉——**不是拉窗口**；右键「重置内容缩放」回 1×；
- **侧键翻页**：鼠标大拇指那两颗键，在放大窗上是**上一页 / 下一页**（靠后那颗下一页、
  靠前那颗上一页），主界面保持不激活；
- **标记颜色**：右键 →「标记窗口颜色」挑一个色，标题条和边框会带上这个颜色，
  开好几个窗时一眼分得清；选「默认」回到主题色；
- **Ctrl+拖动内容**：放大后按住 Ctrl 再按住左键拖，看的那块跟着手走；
  **窗口锁定后也能拖**（锁的是窗口位置大小，不是看的内容），放大到 1× 时没有可移的余量；
  拖动时用的是预览图平移，松手才重渲一张清晰的，所以拖起来是顺的、不会一顿一顿；
- **压在所有窗口之上**：右键勾选「始终显示在所有窗口之上」，切到 CAD、浏览器、资源管理器，
  它也会留在最前面；不勾就只浮在雀雀 PDF 上面，不压别的软件；
- **不抢焦点**：在 CAD 里直接点它、拖它、滚它，都不会把雀雀 PDF 主界面切到前台
  （窗口本身不接收焦点，主界面保持在你原来的软件后面）；
- **锁定**：右键「锁定位置和大小」，锁上后换页照样换内容、Ctrl+滚轮照样能缩放内容；
- **一直在上面**：翻页、缩放、点工具栏都不会把它盖住；**切换标签页也不会消失**，
  会自动跟着新标签的当前页换内容；
- **所有项目共用一套**：窗口数量、各自区域、位置大小、置顶、锁定、标记颜色、内容倍率
  都记在程序设置里，下次启动原样回来；**只恢复上次仍开着的窗口**，已经关掉的不会
  下次又冒出来
  （老项目里原来那份放大区域会自动迁成第一个放大窗）。

## 多标签页（同时开好几份图纸）

窗口最上面那排就是标签页，一个标签 = 一份 PDF + 它的 `.qpdf` 项目，互不干扰。

- **再开一份**：`文件 → 打开 PDF`（Ctrl+O）就会多一个标签；标签左边的 **`+`** 也是同一个作用；
- **切换**：点标签，或者按 `Ctrl+Tab`；滚轮在标签条上滚也能切；
- **拖动排序**：按住标签左右拖；
- **关掉**：点标签上的 `×`，或者 `文件 → 关闭`（`Ctrl+W`）；
  有没保存的改动会先问「保存 / 不保存 / 取消」；
- **各记各的**：切回来时还停在你离开时的那一页、那个倍率、那个模式（浏览/数字/…）；
- **不重复占内存**：不看的标签只放掉高清图，留一张低清预览——切回来第一眼就有画面，
  不像以前那样空白一秒再慢慢画出来；同一份 PDF 或同一个项目不会开出两个标签，
  再打开只会切过去；
- **项目库目录跟着设置走**：设置里换了项目库位置，已经开着的标签也一起换。

## 画面空白 / 显示不对劲时：强制刷新

`视图 → 强制刷新`，或者按 `Ctrl+F5`；工具栏最右边的 `⋯` 里也有「强制刷新」。

它会把当前这一页的缓存全丢掉，按现在的倍率重新渲染一遍（放大窗和当前页的缩略图也一起重画）。
遇到「明明有这一页，画布却是白的」「放大以后还是糊的」这种不听话的情况，先按它；
还不行再关掉标签重新打开。

（2.0.2 之前有个毛病：放大后停在模糊的预览图上，越刷新越白。根因是渲染队列里作废的
任务不回报完成，把同一个位置的请求永久堵死，已经修掉。再遇到就按上面两步走，并把
程序目录 `日志\crash-*.log` 发过来。）

## 改快捷键

**工具 → 设置… → 快捷键**：每一行一个功能，点右边那格、直接按新键就改好；
按 `Backspace` 清空表示这个功能不要快捷键。「全部还原默认」一键回到出厂设置。
同一时刻这个表会查重，两个功能占了同一个键会拦下来告诉你哪两个。

默认值和以前完全一样（比如 `Ctrl+E` 导出、`F5` 文字、`F2` 数字、`Ctrl+Shift+M` 数据匹配），
没改过的项不会留下任何设置。

## 换个样子（浅色 / 浅粉 / 深色、强调色）

`视图 → 界面外观`：浅色 / 浅粉 / 深色三套底子，外加强调色（蓝 / 青 / 石墨 / 朱 / 玫瑰）。

- **只有「取景框」变，图纸永远是白纸**：深色下菜单、工具栏、左边一栏、属性面板
  变深，画布上的纸和图纸内容一点不变——工程图放到深底上，线条和填充就糊了。
  浅粉那套也一样，粉的只是界面，纸照样是白的。
- 选浅粉时会顺手把强调色换成玫瑰（本来用的是默认蓝才换，自己挑过的色不动）；
  从浅粉切走时再换回蓝。强调色菜单里随时能改。
- **浅粉那套画布后面铺的是一张图**（`bg.png`，小兔子在右下角），纸照样是白的，
  图只在纸的四周露出来；没打开文件时的欢迎页会把它整张露出来。
  想换图就把同名 `bg.png` 放进程序目录，下次启动就换（其它主题不用这张图）。
- 选完立刻生效，也会记住，下次启动还是这个。
- 「护眼底色」（`Ctrl+Shift+E`）是另一回事：它只把画布底色换成淡豆绿，
  和深浅主题互不影响。

## 主工具栏上都有什么

窗口窄的时候工具栏会自己收：1400 上下还带文字，1280 左右三个工具按钮只剩图标
（鼠标停上去有名字），再窄连模式按钮也只剩图标、工作台收进最右边的 `⋯`。
把窗口拉宽，文字会自己回来。

从左往右：品牌 → 打开/保存/导出/撤销重做 → 翻页与缩放 → 标注模式 → 干活工具 → 工作台。

- **标注模式**：`浏览` `文字` `数字` `框选`。数字这一个按钮管三种模式，
  按钮上写的就是你现在在用的那个：`数字` / `覆盖` / `插队`；
  在覆盖或插队里点一下它，回到普通数字模式。
  **右键它**能：数字起始值与步长、重新从 1 编号、覆盖、插队。
- **干活工具**：`放大窗`（右键：新建放大窗、设置放大区域）、`材料表`（逐页 OCR
  材料表并导出 Excel）、`数据匹配`（按表格给管线号批量标探伤比例）。
- 最右边 `⋯` 里是强制刷新、护眼底色、显示全部标注——低频的都在那儿，菜单里同样能找到。

## 按表格自动标注（管线号 → 探伤比例）

适用于：图纸上每页有个管线号，你已经有一张 Excel / CSV 记录了每个管线号对应什么值
（第一版只做「探伤比例」这一个字段）。

1. **工具 → 设置识别区域…** 把写管线号的那一块框起来（画布上出现蓝虚线框）；
2. **工具 → 设置标注位置…** 再把希望写字的那一块框起来（绿虚线框）；
3. **工具 → 数据匹配标注…**（`Ctrl+Shift+M`）打开对话框；
4. 点「浏览…」选你的 CSV 或 Excel。软件会自动猜出匹配字段（管线号）和内容字段（探伤比例），
   猜错就在下拉框里改。「模板」可以自己写，比如 `RT {探伤比例}`；
5. **编号取法**（默认「自动」）：图上写的是 `100-BU-V110501-N1B-C50`，表里记的是
   `BU-V110501` 这种两段编号时，用「自动」就能对上；想严格按整串查就选「整串」；
6. 填页码范围 → **开始识别**。一页一行，状态写清楚：已匹配 / 记录冲突 / 未匹配 / 同名跳过 / 已跳过；
7. 觉得没问题的行打钩（默认全打），点 **生成标注**。

几句要说清楚的：

- **表里没有的编号不会硬凑**。它只会列几个「候选」给你看：双击「表里的记录」那一列，
  或者右键「从候选里选」，在弹出的框里挑一条（还能「搜索整张表…」）。
- **同一个管线号在表里有两行**（比如 10% 和 20%），状态会标红「记录冲突」，
  必须双击挑一条，不挑就不生成——防止张冠李戴。
- **同一个管线号出现在好几页上**：默认每页都标。只想标第一次出现那页，
  把「同名只标一次」勾上（设置面板里也有同一个开关），后面那些页记成「同名跳过」，
  想单独标哪页，把那行的钩打回来就行。
- **识别错了编号**：直接双击「识别的编号」那一列改，回车立刻按新编号重查。
- **表里字段是空的**：`/`、`-`、`无`、`n/a` 这些都算空。想让空的地方也写点什么，
  在「字段为空写」里填（比如「未定」）；留空就是这行不生成。
- **要写的字不满意**：双击「要写的字」直接改。改过的行按你写的来，不再套下面的前后缀。
- **想统一加字**：「字前后加」两个框，比如前加 `RT `、后加 ` 级`，所有匹配行都会带上。
  如果「字段为空写」那段默认字你不想带前后缀，勾上「默认字不加前后缀」。
- **没匹配上、也没识别出来的行**：不写字。宁可空着，也不往图上写一串没有意义的前后缀。
- **太长写不下**：文字长度按你框的宽度算，超了就自动缩字号（最小 4pt），不会再出一串字跑到框外面去。
- **表老是要重选**：不用了。上次用的表、工作表、匹配字段、内容字段、模板都记着，
  下次打开对话框会自动接着上次那张表（文件被删了才会安静地不加载）。
- **生成前会提醒**：有人工改过的行、或是写了默认空字段的行，会先弹一个确认框，
  点「更多」能看到具体是哪几页、什么编号、要写什么字，确认了才生成。
- 生成完就是普通文字标注，可以拖动、改字、撤销（一次全退）。导出的 PDF 和平时一样。
- 每一条生成出来的标注都在 `.qpdf` 里记着：原来的管线号、用的哪条记录、哪个字段、
  哪一版表格、内容是不是人工改过，以后能追。

## 按页码直接跳

工具栏中间的「1 / 2712」双击一下，直接在原地输入页码回车，就跳过去了（`Ctrl+G` 也一样）。

## 让 .qpdf 文件显示软件图标

`.qpdf` 项目文件默认是 Windows 的空白图标。想让它显示成雀雀 PDF 的图标（双击也能直接打开）：

1. 打开 **帮助 → 让 .qpdf 显示本软件图标…**；
2. 确认即可。只写当前用户，不需要管理员权限；
3. 如果资源管理器里的图标还没变，注销一次或重启资源管理器。

不想用了：**帮助 → 取消 .qpdf 关联**。

## 设置（工具 → 设置…）

- **缓存上限**：默认 512 MB。机器内存宽裕就往上调，翻回去不容易重新渲染；内存紧张就调小。
  整页预览图另算，按这里的 5/8 折算（默认就有 320 MB 给预览图）。改完立刻生效，**对所有已开的标签页一起生效**。
- **导出文件夹 / 备份文件夹**：默认都在**程序自己所在的文件夹**下的 `输出/`、`备份/`，不往桌面丢东西。
  想放到别处就点「浏览…」选一个，清空输入框就回到默认。
- **同一个管线号只标一次**：不勾（默认）时，一个管线号出现在几页上，这几页都标；
  勾上只标第一次出现的那页，后面同名页记成「同名跳过」，在预览表里还能单独勾回来。
- **渲染线程**：默认 1，可调 1~8。**调大基本不会更快**：PDF 引擎同一时刻只让一个
  线程真正出图，多出来的只是排队抢锁（实测 4 线程比 1 线程还慢 10%~40%）。留在 1 最稳。
- **快捷键**：一张表，点右边那格直接按新键；按 `Backspace` 清空 = 这一项不用快捷键。
  默认值不变，只记跟默认不一样的项；两个功能占同一个键会拦住并告诉你是哪两个。
- **鼠标侧键**：表下面两个下拉，把大拇指那两个键绑到任意功能上（「不用」就是不绑）。
  侧键在雀雀 PDF 是当前窗口时生效；**鼠标停在放大窗上时固定是上一页/下一页**，
  不会触发这里绑的功能。

## 目录树上的三个按钮（左侧「目录树」页）

- **识别编号…**：打开识别窗口，批量读每页上那个位置的编号；
- **导入目录书签**：把这份 PDF 自带的书签目录读进来当目录用（已经有编号的页不会被覆盖）；
- **清空**：清掉识别结果和导入的目录，标注和 PDF 都不动。

「写进 PDF 书签」不在这里，改在**导出 PDF** 对话框里勾选——勾了才把目录覆盖进导出文件的
书签，不勾就保留原 PDF 的书签。

## 识别结果和 PDF 书签对不上时：比对一下再合并

`工具 → 比对书签与识别结果…`（也可以在目录树里右键任一页 →「跟 PDF 书签比对…」）。

打开是一张对照表：第 2 列是 OCR 识别到的编号，第 3 列是这份 PDF 自带书签里这一页的标题，
第 4 列「写进目录树」才是最后会写进去的那个名字（**默认是书签名**，勾上左边那格才换成识别到的编号），最后一列告诉你这一页属于哪种情况：

- **两边一致**：同一页，两边写的一样（全角半角、连字符、大小写不同也算一致）；
- **叫法不同**：同一页但叫法不一样，多半是 OCR 错字或书签名里带括注；
- **只有识别**：这次识别到了，这页原本没有书签；
- **只有书签**：原本有书签，这次没识别出来（或者识别区域没框到它）。

**「写进目录树」这一列默认写的是 PDF 原书签**，不是识别结果——勾上左边那一格，
这一页才换成识别到的编号。所以默认状态下：`两边一致`（名字本来就一样）、
`叫法不同`（保留书签的老叫法）、`只有书签` 都按书签走；只有 `只有识别` 那几页
（原本没书签，不勾就没有名字）默认勾上。

想先只处理有问题的，勾上顶部「只看需要处理的」，把一致的藏起来；
也可以直接点「只勾不一致」「全选」「全不选」「回到建议」。

点右下角「换成目录树（N 条）」之后，**整棵目录树换成这份结果**：

- **没勾、但这页原本有书签**：书签名照旧留着（`只有书签` 那几页就靠这个留下）；
- **勾上的页**：用识别到的编号替换这一页原来的书签名；这页原本没书签就补一条；
- **没勾、原本也没书签**：这一页从目录树里去掉（OCR 猜错的那条不会留下）；
- 写完状态栏会报「目录树已换成 N 条（书签 a 条、识别结果 b 条）」，可以对着看。

为什么是"整棵树换掉"而不是"往树里补几条"：目录树里此刻装的就是上一轮 OCR 的产物，
拿它当底再合并，等于在错稿上改第二遍。改错了也没关系：重新 `Ctrl+Shift+O` 识别一次，
或者再比对一次就行。

### 名字不对？双击改

第 4 列「写进目录树」双击就能改，改完这一行会自动勾上、字变蓝。
识别错个字、或者你想让目录里写「S1-1001（已核对）」这种带备注的写法，都在这里改——
改完它会成为目录树里的正式名字，而书签原来的写法会记进这页的备注（`书签原作：…`），
以后想翻回去还看得到。

标注、PDF 文件都不受影响，随时可以重新识别或再比对一次。

## 放大窗（视图 → 放大窗，Ctrl+Shift+L）

框一块区域后开一个独立小窗，**框住的那块就整块铺满窗口**（横竖各自缩放，不变形、不留白边），
翻到哪页就显示那页的同一块地方。默认**只浮在雀雀 PDF 上面**；右键勾「始终显示在所有窗口之上」
就会压到别的软件前面。可以同时开多个，各看各的区域。

- 拖：按住顶部那行字拖；拉：拖四边或右下角（**宽高各自独立**，右下角有三道斜线就是拉手）；
- **拉高窗口 = 框里那块内容变高**（会按新尺寸重渲，不会糊）；拉宽同理；
- **大小完全由你定**：最小能缩到 40×34（差不多一个点），最大能铺满整块屏幕；
- 滚轮：整体缩放窗口；Shift+滚轮只调宽；Ctrl+滚轮缩放内容（1×–16×，窗口不动）；
- **侧键翻页**：放大窗上按靠后那颗侧键 = 下一页，靠前那颗 = 上一页，主界面不会被激活；
- **标记颜色 / 拖动内容**：右键可给窗口标一个颜色（标题条+边框，多窗好区分）；
  放大状态下**按住 Ctrl 再拖左键**能移动看的那块内容，窗口锁定后也有效；
- **不抢焦点**：放大窗不接收焦点，在别的软件里点它/拖它/滚它不会把雀雀 PDF 主界面带到前台；
- 贴近属性栏/左侧栏/画布边缘 14 像素会自动吸附；拖进属性栏时，只有**本来就差不多那一栏宽**才会贴满，故意放大的窗口不会被缩回去；
- 右键：**设置本窗放大区域…**、**新建一个放大窗**、**标记窗口颜色**、
  **始终显示在所有窗口之上**、**锁定位置和大小**（锁上后换页照样换内容）、
  重置内容缩放、回到右上角、默认大小（320×240）、
  **半屏大小**、**整屏大小**、关闭这个 / 关闭全部；
- 多个窗口的数量、区域、位置大小、置顶、锁定、标记颜色、内容倍率和是否打开
  都记在**程序设置**里（所有项目共用一套），下次启动原样回来；老项目里的放大区域会自动迁成第一个窗口。

## 把页面拖进工作台

打开工作台后，直接从左侧**缩略图**把某一页拖到右侧空白处松手，那一页就落在那儿了。
（也可以在缩略图上右键「把第 N 页加入工作台」，或者按 F8 丢当前页。）

## 管线号目录的排序与筛选

目录树顶部有「排序」和一个「只看待校对」勾选框；搜索框停手 180 毫秒才刷新，输入时不会一顿一顿的。**单击**管线号就跳到它的第一页，双击只是展开/收起。

三种排法（默认**全部收起**，点开一组才铺开）：

1. **按页码**（默认）：不分层，谁先出现在前面的页谁在前；右边列是页码（点多页时显示 `4、9 +3`）；
2. **按数字**：先按开头口径分组（`50` / `100` / `150`…），同一组里按页码排；
3. **按字母**：忽略开头的口径，按第二段介质分组（`CIS` / `CWR`…），组内按后面的字母、数字排
   （`E120301` 排在 `E6102B01` 前面，是纯字符串序，不做数字大小比较）。

「待校对」始终单独一块放最上面，跟三种排法是独立的；它不影响下面的排序。

## 管线号目录的右键菜单

在管线号上点右键：

- **复制编号**：粘到别处；
- **重命名**：名字识别错了直接改，改完写进项目文件（PDF 本身不动）；
- **只看这一组**：搜索框自动填上这个编号；
- **跳到第一页**；
- **按编号导出这几页…**：把这个编号出现的页面提成一个 PDF（标注、书签跟着走）。

排序里选 **按字母**，会忽略开头表示管径的数字段（`100-BU-…` 按 `BU-…` 排），
所以按介质/工位看的时候更顺。

## 检查项目与 PDF 对不对得上

辅助功能在「帮助 → 检查项目与 PDF 是否对应…」。会告诉你旁边的 `.qpdf` 是不是属于这份 PDF；
如果 PDF 被换成了另一版（文件大小变了），它会明确说"对不上"，并且**不会**把旧标注载进来。
真正打开 PDF 时若遇到对不上，会给出「继续加载 / 取消加载 / 查看项目位置」三个选择；继续前自动备份旧项目。

## 拖页面进工作台的手感

现在松手时**卡片中心**对准鼠标，不用再挪一下；拖到窗口边缘会自动滚动；
拖动过程中画面上会有一个虚线影子和一句"松手就放到这里"。

## 项目文件放在哪

**不再跟 PDF 放一起。** 图纸从桌面、U 盘打开时，不会在那儿生成 `.qpdf`。

默认在 `文档\雀雀PDF\项目\`，文件名是「图纸名-指纹前 8 位.qpdf」。
改过一版的图纸会生成**另一个**项目文件，不会把上一版的标注盖掉。

想换地方：**工具 → 设置 → 项目文件夹**，留空就回默认。
老版本留在 PDF 旁边的 `.qpdf` 仍然能用，程序会优先认它。

## 快捷键可以按字母

在图纸上（画布有焦点时）直接按一个字母就切模式，不用记 F 键：

**V** 浏览 · **T** 文字 · **N** 数字 · **O** 覆盖 · **I** 插队 · **S** 框选 · **W** 工作台

在搜索框、改名框里打字时不会误触发——只有画布有焦点才生效。

## 底部那个保存状态

右下角会显示 `● 未保存` 或 `✓ 已保存 23:45`。
自动存档不会把它变成「已保存」——那是存档备份，只有你按 **Ctrl+S** 或关程序时选「保存」才算数。
刚保存完的一瞬间，状态栏左边还会闪一句「已保存 N 条标注到项目文件」。

## 字母快捷键

画布上按一个字母就能换工具，不用记 F 键。这些字母只在画布上生效，
在搜索框、改名框里打字不会被抢走。

| 键 | 作用 |
| --- | --- |
| V | 浏览（拖动画布） |
| T | 文字标注 |
| N | 连续数字标注 |
| O | 覆盖数字 |
| I | 插队 |
| S | 框选 |
| W | 工作台 |
| R | 重新从 1 开始编号（接着连点就是 1、2、3……） |
